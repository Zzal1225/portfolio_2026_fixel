# 4. WebKit에서만 가끔 SKIP이 안 눌림

## 문제
E2E "첫 방문: 인트로 → SKIP → 메뉴 → 창"이 크로미움에서는 늘 통과하고, **WebKit에서만 가끔** 실패했다. SKIP을 눌렀는데 인트로가 계속됐다.

## 원인
SKIP 버튼은 서버 HTML에도 그려져 있었다. Playwright는 버튼이 **보이고 눌릴 수 있으면** 바로 누른다.
WebKit은 하이드레이션(React가 이벤트를 연결하는 단계)이 조금 늦어서, 이벤트가 연결되기 전의 서버 HTML 버튼을 누르는 경우가 생겼다.
사람에게도 같은 문제다. 느린 기기에서 첫 순간에 누르면 아무 일도 없다.

## 해결
인트로 단계에 `'boot'`(서버 HTML·하이드레이션 전)를 추가했다. 이 단계에서는 SKIP을 그리지 않는다.
하이드레이션 후 `'preload'`로 넘어가면서 SKIP이 나타나므로, **보이는 버튼은 언제나 동작한다**.
테스트에 대기 시간을 넣어 넘기는 방법은 버렸다. 실제 사용자 문제를 가리기 때문이다.

## 결과
WebKit 포함 3환경 E2E 3회 연속 통과, 이후 CI에서도 재발 없음.
배운 것: 한 브라우저에서만 가끔 실패하는 테스트는 테스트 탓이 아니라 타이밍 버그일 수 있다. 버튼은 "동작할 수 있을 때만" 보여 준다.
