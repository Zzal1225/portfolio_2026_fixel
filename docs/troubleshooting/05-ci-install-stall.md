# 5. CI가 10분 넘게 멈춤

## 문제
GitHub Actions CI가 평소 4분인데 가끔 10분 넘게 끝나지 않았다(11-10 세 번).
멈춘 곳은 테스트가 아니라 `npx playwright install --with-deps`(브라우저 + 리눅스 의존 패키지 설치)였다.

## 원인
`--with-deps`가 부르는 리눅스 패키지 내려받기가 가끔 응답 없이 매달린다. 코드와 무관한 외부 요인이라 고칠 수 없다.

## 해결
1차: 그 단계에 6분 제한 → 멈추면 실패로 끝나서 사람이 다시 돌려야 했다.
2차: 시도마다 3분 제한(`timeout 180`)을 걸고 **최대 3번 다시 시도**. 평소 설치는 1분 안쪽이라 3분이면 넉넉하다(`.github/workflows/ci.yml`).
함께 줄인 것: CI의 Lighthouse를 3회 → 1회(경고용). 정식 기록은 로컬에서 3회 중앙값으로 남긴다. CI 약 10분 → 약 4분.

## 결과
멈춰도 사람이 개입하지 않고 끝까지 간다. 재시도 후 첫 실행 4분 5초, E2E 37개 통과.
배운 것: 고칠 수 없는 외부 불안정은 "빨리 끊고 다시"로 다룬다. 단계 전체 제한보다 시도 단위 제한이 낫다.
