## 3. 에셋 차이

- 러너 시트는 **128×240**(5행: down·up·right·left 4프레임 + 5행째 인사 2프레임). CLAUDE.md의 128×192와 다름 → 240 기준으로 `sprites.css`를 쓰고 CLAUDE.md 숫자를 고친다.
- CLAUDE.md의 통합 시트(landmarks.png·ui.png)는 없고 구조물·신호등·심판·UI가 **개별 PNG**(선택 상태 `-selected` 포함). step1은 개별 PNG를 그대로 쓰고, step3에서 시트로 합치며 요청 수·전송량 전후를 `docs/performance.md`에 기록하는 쪽을 추천(측정 거리가 하나 생김).
- 소품 시트 128×64(4×2, 32×32 8종: 벤치·콘·물통·가방 / 잔디 패치 1·2·수건 걸이·아이스박스). 기획서의 "1×1칸" 조건과 일치.
- 관중 시트 64×32(4색 × 2프레임). Design은 해시 배치(`SPECTS`)로 관중석 전체에 애니메이션. 기획은 "2~3색 점, 상태 없음" → step1은 정적 1프레임 배경, 애니메이션은 step3에 DOM 수를 재고 결정.
- 소품 배치는 Design이 **실행 시 해시로 계산**(`PLACED`, 18개). 우리는 `layout.ts`에 좌표 상수로 옮긴다. 추출은 step1 작업 2에서 Node 스크립트로 한 번만 돌린다.
- 월드 한 장 PNG(world-640x360-no-runner.png)는 Design 확인용·MAP 창 배경 후보로만 쓰고, 월드 배경은 타일 4종 반복으로 그린다(CLAUDE.md).
- `title-plate-24x10.png`, 신호등 "4상태"는 off·red·yellow·green 4장으로 있음. 심판은 flag-up·flag-down 2장.

## 4. 좌표 변환 사실 (trackPath.ts에 그대로 쓰는 값)

- 러너 선 반지름 100, 레인 폭 32(반지름 84~116), 흰 레인 선 84·94·105.
- `s=0` = 아래 직선 x=320(분필 출발선), s 증가 = 오른쪽으로 = 화면 반시계(y축이 아래로 커지므로).
- 구간: 아래 직선 0~140 → 오른쪽 반원 140~454.16 → 위 직선 454.16~734.16(x 감소) → 왼쪽 반원 734.16~1048.32 → 아래 직선 1048.32~1188.32(x=180→320).
- 러너 **발** 위치 y = 선 위 y + 12. 스프라이트 32×48은 (x−16, 발y−48)에 그린다.
- 바라보는 방향: 직선은 진행 방향, 반원은 접선 각도 ±45° 기준으로 right/up/left/down.
